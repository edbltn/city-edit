1 · feedback.cityedit.org — a form that emails the team

Goal

There was no way for users to reach us. Donate already had the pattern: a *.cityedit.org subdomain mapped to the same Cloud Run service and answered at the nginx layer (donate 301-redirects to Donorbox). Feedback follows it, but serves a real page: a form whose submissions land in eric@sphericalharmonics.org + brook@sphericalharmonics.org.

Design

  • The server has no SMTP/email stack, and adding one (plus a queue, spam handling, secrets) for a feedback form is overkill. FormSubmit.co is a no-backend form-to-email relay: the static page POSTs to formsubmit.co/eric@sphericalharmonics.org with a hidden _cc to Brook, a honeypot field for bots, and a _next redirect back to the page (?sent=1 shows the thank-you banner).
  • The page itself is client-react/public/feedback.html — Vite copies public/ into dist/ verbatim, so it ships inside the existing client build with zero new build steps. It reuses the app's terminal aesthetic (Red Hat Mono, #0d0d0d paper, hairline borders, amber accent).
  • nginx answers the subdomain before the catch-all SPA server: every path on feedback.cityedit.org lands on /feedback.html.

What changed

  • New static form page client-react/public/feedback.html — name (optional), reply-to email (optional), message; posts to FormSubmit with _cc, _subject, honeypot, and a success banner on return.
  • nginx server block for feedback.cityedit.org in deploy/nginx-cloudrun.conf, mirroring the donate block's placement.
  • Terraform: feedback.cityedit.org added to custom_domains, so a targeted apply creates the Cloud Run domain mapping (the app service itself is never applied via terraform — see the deploy-landmines runbook).
  • One manual step: a Namecheap DNS CNAME feedback → ghs.googlehosted.com (DNS for cityedit.org is registrar-hosted, not in terraform).
  • One activation step: FormSubmit sends a one-time activation email to eric@sphericalharmonics.org on the first submission; until it's clicked, submissions aren't relayed.

2 · Header rework — Feedback · About · Donate on one line

Goal

The map-page header had How-it-Works + Donate sharing a grid cell. Wanted: Feedback, About (→ sphericalharmonics.org), and Donate together on one line, Donate colored by the active map theme, and How-it-Works moved down to the Cast/Clear row. Same trio on the landing footer.

Design

  • .topbar-actions is a strict 2×2 grid (Mode / header links over Vote / actions), so the three links stay wrapped in .header-btn-group to keep 4 grid children, and How-it-Works simply moves into .actions-group (the Cast/Clear cell).
  • On mobile (≤1080px) the second grid row used to collapse to 0 height until a selection existed — it held only the then-hidden Cast/Clear controls. With the always-visible How-it-Works button living there, the collapse would hide it, so the row now stays open.
  • Theme coloring: ThemeContext already injects the active map style's accent as --accent on the document root (with an amber fallback pre-JS). Every theme accent is a bright mid-tone, so near-black text keeps ≥4.4:1 contrast on all of them — the Donate button just paints background: var(--accent).

What changed

  • TopBar.tsx: header cell now renders Feedback (→ feedback.cityedit.org), About (→ sphericalharmonics.org), Donate — all external links; the How-it-Works <button> moved to the front of .actions-group on the Cast/Clear row (its modal state stays in TopBar).
  • TopBar.css: .btn-donate gets the accent background, accent border, near-black bold label, and a brightness hover; links in the group share text-decoration: none.
  • globals.css: the ≤1080px second-row collapse (grid-template-rows … 0 + .has-selection override) replaced by an always-open second row, since How-it-Works now lives there.
  • Landing.tsx: footer now reads About · Feedback · Donate (the old sphericalharmonics.org label became About).

For you

Manual checklist

  • Click the FormSubmit activation link — submit the form once on feedback.cityedit.org, then open eric@sphericalharmonics.org's inbox and confirm the FormSubmit activation email; until it's clicked no feedback is relayed. Then submit again and confirm both eric@ and brook@ receive it.
  • Add the DNS record at Namecheap: CNAME feedback → ghs.googlehosted.com (same as donate). Until then feedback.cityedit.org won't resolve; the buttons will 404 at the DNS level.
  • On a map page, confirm the Donate button picks up each theme's accent (amber on walkways, green on bikes) and the label stays readable.
  • On a phone-width window, confirm How-it-Works is visible below the mode row before any selection is made, and that Cast/Clear appear next to it after selecting a route.
  • Open the How-it-Works modal from its new spot; confirm it still opens/closes.
  • On the landing page footer, click About / Feedback / Donate and confirm the three targets.
