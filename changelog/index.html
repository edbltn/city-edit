2026-06-17

The mobile-Safari heatmap crash was the graph's own memory

"A problem repeatedly occurred" on phones (bikepaths and the other NYC street maps) wasn't the server, the subdomain routing, or vote-sync — those were ruled out one by one. The foot-aligned rebuild doubled the NYC graph to 3.3M edges, and the client decoded its 35 MB binary blob into ~497 MB of boxed JS tuples, over mobile Safari's per-tab budget. Backed the topology with flat typed arrays (coords/ends + CSR adjacency) read through accessors — ~497 MB → ~71 MB, off the object heap entirely.
2026-06-17

Unifying the icon-explode model — one cluster fanned out at a time

Crowded proposal icons fan out ("explode") into a grid so you can pick one from a stack. The state behind it was two overlapping spread maps merged on every render — built to keep several clusters open at once. Collapsed them into a single spread plus a lock flag, routed all cluster detection through one clusterAround() helper and collapsing through one collapseSpread(), and made a fresh fanout replace the open one — so exploding any icon set un-explodes the others.
2026-06-17

Removing ferry edges from routing and the display graph

Ferry ways tagged foot=yes (Staten Island Ferry, Governors Island, NYC Ferry…) were slipping past the "ferries disabled" foot profile via an access fallback shared by OSRM and its Python mirror — so routes jumped open water and ferry lines lingered in the hover graph. Added an explicit route=ferry cutoff to both, rebuilt every graph + the OSRM dataset, and added a reverse-coverage check that keeps the two graphs consistent.
2026-06-17

Expansion groundwork — Philadelphia (and finishing D.C.)

Registered Philadelphia end-to-end (city registry, merged-OSRM clip, and a freshly built 505K-node walk graph), derived the resident-graph budget from the registry, and seeded preset Bikes/Trees/Walkways maps so both D.C. and Philly are reachable out-of-the-box.
2026-06-14

Backend caching + concurrency, and the zoom overhaul

Fixed the stale-cache crash that looped mobile Safari on heatmap load (NYC e-bikes), made the backend safe under multiple tenants and more than one Flask instance, and reworked the heatmap so it scales smoothly on zoom instead of disappearing.
